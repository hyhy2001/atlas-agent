---
name: explain
description: Explain how a piece of code works in detail
---

Explain the code the user points to. Use read_file and list_directory to explore the relevant files.

Structure your explanation:
1. **What it does** — high-level purpose
2. **How it works** — step-by-step walkthrough
3. **Key concepts** — important patterns or techniques used
4. **Data flow** — how data moves through the code
5. **Dependencies** — what it relies on

Use ASCII diagrams where helpful. Match the explanation depth to the complexity of the code.
Respond in the same language the user used to ask.
