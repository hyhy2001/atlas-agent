---
name: review
description: Review code for bugs, security issues, and improvements
---

Review the code in the specified file or directory. Check for:
1. Bugs and logic errors
2. Security vulnerabilities (injection, hardcoded secrets, unsafe operations)
3. Performance issues
4. Code style and readability
5. Missing error handling
6. Test coverage gaps

Use read_file and grep to examine the code thoroughly. Provide a structured report with:
- **Critical issues** (must fix)
- **Warnings** (should fix)
- **Suggestions** (nice to have)

Be specific: include file names, line numbers, and concrete fix suggestions.
